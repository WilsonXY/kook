# Trim dev-skills to the core delivery cycle

**Context.** The first dev-skills import brought 11 skills. Most never fired in real work.

**Decision.** Keep only skills that change what an agent does in an implement, test, review, PR cycle. Removed (still in git history): spike, dogfood, stacked-prs, codebase-inspection, node-inspect-debugger, python-debugpy, service-monitoring, linux-user-services.

**Why.** Fewer skills beat more. Each one is upkeep and competes for the agent's attention.
